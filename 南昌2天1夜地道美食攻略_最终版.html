01｜详细行程

路线按营业时间 + 胃容量 + 地理方向综合优化

时间基准：你最新说返程是第二天18:30，我已按18:30重新安排；如果实际车票仍是18:00，请把老菜香整体提前30分钟。

DAY 1｜第一顿清爽切入，晚上老城一路吃

南昌站 → 红灯笼 → 酒店 → 滕王阁 → 杨大娘 → 辣小鲜蛤蟆街 → 八一广场（首选）→ 季季红 → 酒店
13:00

抵达南昌站

空腹第一顿不碰油炸，直接去羊子街红灯笼水煮。

13:20–14:05

红灯笼水煮（羊子街店）

建议少辣、少量多样：年糕、油条、荷包蛋、芋头/玉米笋、豆肠等选3–5样。店面偏小，晚高峰更容易等位，因此13点后去反而比较合适。

14:05–14:30

前往酒店

网约车前往南昌滕王阁希尔顿花园酒店；15:00前若房间未好，先寄存行李。

14:30–16:20

酒店休息

给第一顿留消化时间，也避开下午最晒时段。

16:25–18:05

滕王阁

酒店与滕王阁很近，步行即可。这个时段能兼顾白天登阁、傍晚江景和亮灯前后的氛围。

18:10–18:30

万寿宫｜杨大娘粽子

从滕王阁顺路去万寿宫，建议买咸蛋黄肉粽，分食或打包，不要吃太饱。

18:35–20:00

辣小鲜·南昌大排档（大士院蛤蟆街店）

正式晚餐。近期蛤蟆街内容高频推荐霸王辣蟹脚、油浸鱼；品牌曾提示16:00前较容易免排队，因此晚餐档需预留等位。

20:10–20:45

八一广场｜主推荐

比秋水广场更顺路。吃完辣小鲜后向八一广场移动，再乘地铁1号线回万寿宫吃季季红。

20:10–21:00

秋水广场｜替代方案

如果更想看赣江夜景/音乐喷泉，可替换八一广场，但之后回万寿宫会产生明显折返。

21:15–22:30

季季红火锅（万寿宫店）

夜宵。营业常见为10:00–24:00。分量偏足，建议小锅+少量肥牛/虾滑/冻豆腐/毛肚。

22:35以后

返回酒店

万寿宫离酒店较近，步行或短途打车返回。

DAY 2｜大士院过早 → 午间小吃 → 老菜香 → 南昌东站

酒店 → 大士院早餐圈 → 酒店退房寄存 → 陶福坤 → 中山路慢逛 → 取行李 → 老菜香 → 南昌东站
07:45

从酒店出发

目标08:00左右到大士院。

08:00–08:35

小罗子汤店（大士院总店）

先吃最容易排队的。建议拌粉+皮蛋肉饼汤；8点前后比9点后更稳。

08:35–08:55

江鹰包行

吃现蒸小笼包/包子，趁热最佳。

08:55–09:15

福顺记油条包麻糍

油条包麻糍、马打滚二选一或两人分食，避免太顶胃。

09:15–09:35

陶记绿豆饼

建议经典绿豆馅。紫薯/芋泥评价分化，原味更稳。

09:35–10:00

大士院自由补漏

看排队情况补白糖糕或豆浆，不要为了凑店数硬吃。

10:00–11:30

回酒店休息

回酒店消食、整理行李。

11:30–12:00

退房并寄存行李

酒店官方退房时间12:00，行李先寄存在酒店。

12:05–12:55

陶福坤馄饨烧饼王（动壹店）

安排为午间加餐。建议馄饨+烧饼小份组合；公开网页索引较弱，出发当天再确认具体楼层和营业状态。

13:00–14:20

万寿宫 / 中山路慢逛

咖啡休息、散步消食，不再加重口正餐。

14:20–14:40

回酒店取行李

取完行李后直接向东移动。

14:45–15:20

前往老菜香

建议网约车。

15:25–16:35

老菜香烧菜馆

压轴正餐。高频推荐黄豆鸡脚、鱼籽鱼泡、牛蛙；整体辣度偏高，建议主动说微辣/少辣。

16:40–17:20

前往南昌东站

预留晚高峰与进站时间。

17:20–18:30

南昌东站候车

按你最新说的18:30车次，留约1小时以上缓冲。

02｜第一晚：八一广场 vs 秋水广场

主线选效率更高的一套

✅ 主推荐：八一广场

优势是路线顺。辣小鲜吃完往八一广场移动，再乘地铁1号线回万寿宫吃季季红，不需要跨江折返；而且八一广场本来就在你最初指定景点里。

🌊 替代：秋水广场

如果你更看重赣江夜景和音乐喷泉，就把八一广场替换掉。但从蛤蟆街跨江到秋水广场、再回万寿宫吃夜宵，会多一段往返，因此属于“景观优先”而不是“效率优先”。
